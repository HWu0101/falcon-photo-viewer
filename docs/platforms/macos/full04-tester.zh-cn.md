# macOS 版本检查

Falcon Photo Viewer Mac 版。Mac 版保留免费的临时签名，
不计划购买开发者签名或公证；首次启动的系统提示属于已接受的发行限制，不是发布阻碍。

首次打开可信下载的 Falcon.app 若被系统阻止，请到“系统设置 → 隐私与安全性”，找到该应用的提示，
点击“仍要打开”并确认。保留系统整体安全保护；受单位管理的电脑可能不允许例外。
参考 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

测试普通版本的文件关联时，请替换已安装的旧 Falcon.app。同一应用标识的多个副本可能导致 macOS 打开错误版本。
更新时，请用新版本替换“应用程序”中的旧 Falcon.app，不要同时保留两个副本；双击照片前请先打开一次新版本。涉及评分、标记或文件修改的测试请使用照片副本或合成图片。

检查普通窗口和绿色按钮全屏模式下的工具栏位置，反复进入/退出全屏、顶部悬停、窗口缩放及跨屏移动。
测试 F 沉浸模式、英文和拼音输入、设置、排序、右键菜单和键盘焦点。确认“打开方式”和默认关联启动的是此版本，
并确认原有设置与照片审核记录仍能正常读取。

开发者设置中的诊断日志默认关闭，仅在排查问题时开启。分享日志前请检查个人路径和照片元数据。
反馈时请附源码版本、macOS 版本、准确复现步骤以及必要的截图或录屏。

**注销、重新启动和关机**（1.0.15 之后、包含注销修复的构建）。先打开 Diagnostic logging，
使用照片副本，并保存其他应用中的工作。给几张照片评分或标记后立即注销。macOS 不应提示
Falcon 中断了注销，一次即可完成。重新登录后打开文件夹，确认最后的评分和标记仍在。再分别用
重新启动和关机重复一次；其中一次打开 XMP 同步，并检查 XMP 文件。然后确认 ⌘Q 和 Dock →
退出仍会立即关闭、没有新的提示且保留更改；有未应用的旋转时关闭窗口仍会显示提醒。最后在
照片副本上开始 Copy picks，并在复制过程中注销：已完成的副本能打开，原片不变，评分保留。
日志中应出现 `terminate: system reason=`，之后是 `terminate: reply=now`。如出现
`STILL running at the boundary deadline`、`FLUSH BARRIER exceeded` 或
`final ratings flush failed`，这次测试不能证明已保存；无论如何，重新登录后都要检查文件。
