# Release status

Releases are published on the [GitHub Releases page](https://github.com/HWu0101/falcon-photo-viewer/releases); use the source and binary archives from the same release.

The release downloads include matching application and dependency sources, licence notices,
build instructions and SHA256 checksums. See [BUILDING.md](BUILDING.md) and
[REBUILDING.md](REBUILDING.md) for building from source and modifying the RAW library.

Windows downloads are unsigned, and Mac downloads are ad-hoc signed without Apple
notarization. The README's [Download and first launch](README.md#download-and-first-launch)
section explains the operating-system prompts and how to allow the app to run. No paid certificate is required to build Falcon yourself.
